# Agent 学习路径 · 导读

- 先搞清楚：Agent 是什么
  - 一句话：能自己决定下一步做什么、并调用工具把事做完的 LLM 程序
  - 和普通聊天机器人差在哪：有目标、有工具、有循环、有记忆
  - 和 Workflow 差在哪：Workflow 路径写死，Agent 由模型临场选路
  - 核心循环：观察 → 思考 → 行动 → 再观察，直到完成或放弃
- 第一阶段：打地基
  - Python 基础：函数、类型、异常、异步 async/await
  - HTTP 与 API：请求响应、鉴权、超时、重试
  - LLM 基本概念：token、上下文窗口、温度、流式输出
  - Prompt 基础：角色、指令、示例、输出格式约束
  - 小目标：写一个能稳定调用模型并解析结果的脚本
- 第二阶段：让模型会动手
  - Function Calling / Tool Use：把函数描述成 schema 交给模型
  - 工具设计三原则：职责单一、参数少而明确、错误信息可读
  - 结构化输出：JSON Schema、校验、失败重试
  - MCP：用统一协议接文件、数据库、浏览器等外部能力
  - 小目标：做一个能查天气 + 查数据库 + 汇总回答的助手
- 第三阶段：给 Agent 加记忆
  - 短期记忆：对话历史、上下文裁剪、摘要压缩
  - 长期记忆：向量库、Embedding、相似度检索
  - RAG：切块、召回、重排、拼进上下文
  - 记忆管理：什么该记、什么该忘、如何避免污染
  - 小目标：做一个能记住你偏好、并基于文档回答的 Agent
- 第四阶段：让 Agent 会规划
  - ReAct：边想边做，Thought / Action / Observation 循环
  - Plan-and-Execute：先列计划再逐步执行
  - Reflection：做完自检、发现错误后重试
  - 任务分解：把大目标拆成可验证的小步骤
  - 多 Agent：分工、通信、汇总，警惕复杂度爆炸
  - 小目标：做一个能自主完成多步骤研究并输出报告的项目
- 第五阶段：工程化
  - 可观测性：记录每一步的输入、输出、耗时、成本
  - 评测：建固定测试集，量化成功率而不是只看 demo
  - 护栏：输入输出校验、敏感操作审批、人工兜底
  - 成本与延迟：模型分级、缓存、并发、流式返回
  - 可靠性：超时、重试、幂等、断点续跑
  - 小目标：给前面的 Agent 补上日志、评测和失败恢复
- 安全必修课
  - Prompt Injection：外部内容一律当不可信数据
  - 最小权限：工具只给完成任务必需的范围
  - 沙箱隔离：代码执行、文件访问、网络访问要受限
  - 密钥管理：不把 key 写进提示词和日志
  - 高危动作：删除、支付、发消息前必须确认
- 常用框架与工具
  - Claude Agent SDK：工具循环、子 Agent、权限控制
  - OpenAI Agents SDK：handoff、guardrails、tracing
  - LangGraph：用图描述状态与分支，适合复杂流程
  - LlamaIndex：偏数据接入与 RAG
  - CrewAI / AutoGen：多 Agent 协作快速原型
  - 选型建议：先手写循环理解原理，再上框架
- 推荐学习顺序
  - 周 1–2：LLM 基础 + Prompt + 第一次 API 调用
  - 周 3–4：Function Calling，手写一个最小 Agent 循环
  - 周 5–6：加 RAG 与长期记忆
  - 周 7–8：加规划、反思与多工具协作
  - 周 9–10：补评测、可观测性、安全与成本
  - 周 11–12：做一个完整项目并写复盘
- 可做的练手项目
  - 个人知识库问答 Agent
  - 自动整理会议纪要并生成待办
  - 代码仓库巡检 Agent：跑测试、定位失败、提修复建议
  - 网页研究 Agent：多来源检索、交叉验证、输出报告
  - 本地文件管家：按规则整理、重命名、归档
- 学习资源
  - 官方文档：Anthropic / OpenAI 的 tool use、MCP、Agent 指南
  - 经典论文：ReAct、Toolformer、Reflexion、Self-Refine
  - 实践材料：Agent SDK 示例、MCP 官方 server 列表
  - 进阶阅读：context engineering、eval-driven development
- 常见坑
  - 一上来堆框架，不理解工具循环
  - 工具太多太杂，模型选错工具
  - 上下文塞太满，关键指令被淹没
  - 没有评测，改一版坏一版
  - 忽略权限与注入风险，拿生产数据直接试
