# 八股样例 · 纲要派

## MySQL 索引

### 数据结构
- B+ 树：多叉平衡树 / 非叶子只存键 / 叶子存全量数据
- 树高约 3 层 → 磁盘 IO 少 → 查询快
- 叶子链表串联 → 范围查询顺序扫描

### 索引类型
- 聚簇索引：主键 / 叶子即数据行
- 二级索引：非主键 / 叶子存主键 → 回表
- 覆盖索引：查询列全在索引里 → 免回表

### 失效场景
- 最左前缀：联合索引 (a,b,c)，跳过 a 直接用 b → 失效
- 函数/运算：`where year(create_time)=2026` → 失效
- 隐式转换：varchar 列拿数字去比 → 失效
- 前置通配：`like '%abc'` → 失效

## 事务

### ACID
- 原子性 Atomicity / 一致性 Consistency / 隔离性 Isolation / 持久性 Durability
- 隔离性靠 锁 + MVCC 一起撑

### 隔离级别
- 读未提交 → 脏读
- 读已提交 → 不可重复读
- 可重复读（默认）→ 幻读（InnoDB 用间隙锁挡）
- 串行化 → 全串行，性能最差

### MVCC
- 版本链：每行有隐藏列 trx_id / roll_pointer
- ReadView：判断哪个版本对当前事务可见
- RC：每次查询都新建 ReadView → 所以不可重复读
- RR：事务首次查询建一次 → 所以可重复读
